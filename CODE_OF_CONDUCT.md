# Contributor Code of Conduct

## Our commitment

We are committed to providing a friendly, safe, and welcoming environment for
all contributors, regardless of background or experience level. This is an
early public-alpha candidate, and we value clear, respectful collaboration.

## Expected behavior

- Be respectful and considerate in all interactions.
- Assume good faith; critique ideas, not people.
- Keep discussions focused on the public package and its roadmap.
- Report security concerns through the private channel described in
  `SECURITY.md`, not as public issues.

## Unacceptable behavior

- Harassment, discrimination, or personal attacks of any kind.
- Publishing others' private information without explicit permission.
- Submitting secrets, private knowledge/data, machine paths, or generated
  private evidence to this public repository (see `CONTRIBUTING.md`).
- Opening public issues to report security vulnerabilities (use the private
  reporting path instead).

## Scope

This Code of Conduct applies to all repository spaces — issues, pull requests,
discussions, and any other project communication — and to any contributor
acting in an official capacity on behalf of the project.

## Enforcement

Reports of unacceptable behavior should be directed privately to the
maintainers. Maintainers may moderate, remove, or reject contributions that
violate this policy. Decisions are made to protect the health of the project
and its community.

## Attribution

This Code of Conduct adapts the spirit of the Contributor Covenant (version
1.4), a widely used open-source conduct baseline, to the scope of this public
alpha candidate.
