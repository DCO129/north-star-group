# Contributing (pointer)

The authoritative contribution guide is the repository-root
[CONTRIBUTING.md](../../CONTRIBUTING.md). This `docs/public/` copy is a short pointer
only; all rules, the development flow, and the pull-request requirements live in
the root file. In short: submit only public-safe changes, keep them on the
export allow-list, run the lightweight validation, and declare scope, tests,
public/private-boundary impact, and any external effects or model calls.
