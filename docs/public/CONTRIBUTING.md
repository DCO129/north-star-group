## 中文 / Chinese

简言之：只提交公开安全的改动，保持它们在导出白名单上，运行轻量验证，并声明范围、测试、公开/私有边界
影响，以及任何外部效应或模型调用。缺陷、反例、架构异议与安全报告都算贡献；社区贡献者不是无偿外包人员。

## English

In short: submit only public-safe changes, keep them on the export allow-list, run the
lightweight validation, and declare scope, tests, public/private-boundary impact, and any
external effects or model calls. Defects, counterexamples, architecture objections, and
security reports all count as contributions; community contributors are not unpaid
outsourcers.
