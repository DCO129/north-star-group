# Operations Orchestration Skill

Purpose: convert an approved CEO objective into ordered assignments, checkpoints, evidence and deliverable artifacts.

Inputs: objective, acceptance criteria, routed departments, permissions and dependencies.

Outputs: work breakdown, execution order, responsibility map, checkpoints, verification gates and escalation codes.

Hard rules:

- Every assignment has one accountable department.
- Internal machine traffic uses Group IR, not prose.
- A task cannot reach the human-report state before verification.
- Missing authority, evidence or executor capability blocks execution and returns to the CEO.
